أَثَر — حزمة تجهيز للنشر (PWA + Node.js + Supabase + AI)
========================================================

ما الذي أصبح موجودًا؟
- تطبيق القرآن والتدبر مع متابعة آخر موضع ودفتر خواطر محلي.
- مساعد ذكاء اصطناعي داخل الواجهة عبر /api/ask؛ المفتاح يبقى في متغيرات الخادم، ويتطلب تسجيل الدخول ويتحقق الخادم من جلسة Supabase.
- إنشاء حساب بالبريد وكلمة المرور وتسجيل الدخول والخروج عبر Supabase Auth.
- مجتمع منشورات وإعجابات وتعليقات وبلاغات.
- رسائل خاصة بين مستخدمين باستخدام اسم المستخدم، مع حالة مقروءة وبلاغ عن رسالة.
- صفحات الخصوصية والشروط، وPWA للتثبيت على الهاتف، وملفات إعداد نشر Node.js.

قبل أن يعمل الموقع مع الجميع، يلزم تنفيذ هذه الخطوات الخارجية:
1) أنشئ مشروع Supabase، ثم نفّذ supabase_schema.sql كاملًا في SQL Editor.
2) في Authentication فعّل Email provider واضبط تأكيد البريد وإعادة التوجيه حسب رابط موقعك المنشور.
3) انسخ Project URL وPublishable/anon key إلى supabase-config.js. لا تضع service_role key في الواجهة.
4) انشر هذا المجلد على استضافة Node.js مثل Render باستخدام render.yaml أو إعداد خدمة Node يدويًا.
5) أضف OPENAI_API_KEY وSUPABASE_URL وSUPABASE_ANON_KEY كمتغيرات بيئة في الاستضافة. لا تضع المفتاح السري في index.html أو Git.
6) بعد النشر اختبر /api/health، ثم أنشئ حسابين مختلفين على جهازين واختبر المنشورات والرسائل والبلاغات.

ملاحظات مهمة:
- لا يوجد رابط عام أو قاعدة بيانات مفعّلة تلقائيًا داخل هذه الحزمة؛ يلزم ربط حسابات الخدمات.
- إعداد الذكاء الاصطناعي قد يحتاج حساب API مدفوعًا ورصيدًا لدى المزوّد.
- النص القرآني والتلاوة يستخدمان خدمة خارجية ويحتاجان الإنترنت.
- الحزمة PWA قابلة للتثبيت من المتصفح بعد النشر على HTTPS؛ ليست APK أصليًا.
- راجع privacy.html وterms.html وأكمل بيانات التواصل وسياسة حذف الحساب قبل الإطلاق العام.
